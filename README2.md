# Student Management v2

A modern React-based student management dashboard built as a lightweight `v2` version of a traditional C++ student management project.

## Overview

Student Management v2 converts a basic console-style project into a simple dynamic website. It allows users to manage student records through a clean dashboard interface with real-time search, filters, editing, and local data persistence.

## Features

- Add new student records
- Edit existing student details
- Delete student entries
- Search by name, roll number, or department
- Filter students by status
- View quick dashboard statistics
- Persist data with localStorage

## Built With

- React
- JavaScript
- Vite
- localStorage
